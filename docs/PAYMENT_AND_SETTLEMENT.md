# 支付与结算

## 周末灰度模式

当前没有平台经营主体和审核通过的微信支付产品，因此生产在线代收默认关闭。

- `MOCK`：仅开发/测试环境；模拟幂等支付通知。
- `OFFLINE_MERCHANT_DIRECT`：用户直接向订单所属商家的收款码付款，平台不经手货款。运营或商家人工确认仅代表线下确认，不是微信支付回调。
- 不提供平台余额、充值、商户提现或平台收款后人工结算。

配送/技术服务费通过商家协议和周期账单形成平台应收，由商家另行支付。骑手报酬按已完成配送生成结算单，线下付款后记录凭证。

## 正式支付迁移

1. 注册企业或由合规运营主体承接小程序。
2. 完成小程序备案、外卖平台类目和商家食品资质核验。
3. 优先接入现有微信支付服务商，由商家以子商户身份直接收款。
4. 规模扩大并具备准入条件后申请平台收付通，启用官方冻结、解冻、分账和退款回退。

接入真实支付前必须确认：

- AppID、服务商商户号、子商户号的绑定关系。
- 支付回调公网 HTTPS 域名。
- 平台证书轮换、APIv3 Key 和商户私钥保管方式。
- 商户展示名称、费率、退款权限和账单下载权限。
- 微信支付 95017 对校园多商家外卖场景的产品路径书面/工单结论。

## 资金安全不变量

- 支付成功以验签回调或主动查单为准。
- 回调核对商户号、订单号、金额和币种。
- 支付单、退款单、微信通知 ID 均唯一。
- 退款申请成功不等于退款成功；以回调/查单为准。
- 账务流水只追加，纠错写反向分录。
- 每日按渠道账单对账，差异进入人工工单。
