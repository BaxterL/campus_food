# 校园外卖 campus_food

基于 [yshop-drink](https://github.com/guchengwuyue/yshop-drink)（MIT）复制改造的校园自取外卖 P0。

## 目录

| 路径 | 说明 |
|------|------|
| `backend/` | Spring Boot 3 · Java 17 API（端口 48081） |
| `admin/` | Vue3 管理后台 |
| `miniapp/` | uni-app 学生端（微信小程序 / H5） |
| `web/` | P0 静态视觉稿（Sleek，浏览器直接打开） |
| `DEMO.md` | 启动与自取一单走通说明 |
| `docs/` | 缺口与微信配置占位 |

## 快速开始

- **Windows 本地（推荐）**：[docs/WINDOWS.md](./docs/WINDOWS.md)
- 通用说明：[DEMO.md](./DEMO.md)
- 可选 WSL：[docs/WSL.md](./docs/WSL.md)
